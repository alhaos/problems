# Heap с компаратором

Реализуй бинарную кучу над `int`, порядок которой задаётся функцией `less`.
Элемент на вершине это тот, для которого `less(top, x)` истинно по отношению
ко всем остальным.

- `New(less)`: пустая куча
- `From(items, less)`: куча из слайса
- `Push(x)`: O(log n)
- `Pop() (int, bool)`: убрать и вернуть вершину, `(0, false)` если пусто. O(log n)
- `Peek() (int, bool)`: вершина без удаления. O(1)
- `Len() int`

Примеры:
- `New(func(a, b int) bool { return a < b })` это мин-куча
- `New(func(a, b int) bool { return a > b })` это макс-куча

## Требования
- Никаких `container/heap`, только свои `siftUp` / `siftDown`.
- Один и тот же код для мин и макс, никаких дублей с перевёрнутыми знаками.

## Дополнительно
`From` за O(n) через heapify (siftDown от середины к корню), а не n раз `Push`.
