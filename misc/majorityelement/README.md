# Majority Element (Преобладающий элемент)

## Условие

Дан массив `nums` размера `n`. Найти преобладающий элемент — тот, что
встречается **более `n/2` раз**.

Гарантируется, что такой элемент в массиве существует (то есть всегда
ровно один ответ).

### Пример 1

```
Input:  nums = [3,2,3]
Output: 3
```

### Пример 2

```
Input:  nums = [2,2,1,1,1,2,2]
Output: 2
```

## Ограничения

- `n == len(nums)`
- `1 <= n <= 5*10^4`
- `-10^9 <= nums[i] <= 10^9`

## Требуется

Реализовать функцию

```go
func MajorityElement(nums []int) int
```

## Follow-up

Решить задачу за:
- время: **O(n)**
- память: **O(1)**

(Это исключает вариант с хэш-таблицей подсчёта — он O(n) по памяти.
Подсказка: алгоритм голосования Бойера-Мура.)
