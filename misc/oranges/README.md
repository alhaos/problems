# Rotting Oranges

Дана сетка `grid`, в каждой клетке:
- `0` пусто
- `1` свежий апельсин
- `2` гнилой апельсин

Каждую минуту каждый свежий апельсин, стоящий рядом (сверху, снизу, слева или справа)
с гнилым, тоже становится гнилым.

Верни минимальное число минут, за которое не останется свежих апельсинов.
Если это невозможно, верни `-1`.

## Примеры

[[2,1,1],
 [1,1,0],
 [0,1,1]]  -> 4

[[2,1,1],
 [0,1,1],
 [1,0,1]]  -> -1   (левый нижний апельсин никогда не загниёт)

[[0,2]]    -> 0    (свежих нет, ждать нечего)

## Ограничения

- 1 <= m, n <= 10
- grid[i][j] это 0, 1 или 2
