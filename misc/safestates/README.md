# Find Eventual Safe States

Дан ориентированный граф из `n` узлов (0..n-1), заданный списком смежности `graph`,
где `graph[i]` — список узлов, в которые есть рёбра из `i`.

Узел называется "безопасным" (safe), если из него **нельзя** попасть в цикл,
двигаясь по рёбрам (сколько угодно шагов, в любом направлении по рёбрам).

Верни список всех безопасных узлов, отсортированный по возрастанию.

## Примеры

graph = [[1,2],[2,3],[5],[0],[5],[],[]]
-> [2,4,5,6]

graph = [[1,2,3,4],[1,2],[3,4],[0,4],[]]
-> [4]

## Ограничения
- n == graph.length
- 0 <= n <= 10^4
- рёбра могут вести куда угодно, включая петли на себя
