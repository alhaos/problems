# Number of Islands

Дана сетка `grid` из символов `'1'` (суша) и `'0'` (вода).
Верни количество островов.

Остров — группа `'1'`, соединённых по горизонтали или вертикали (по диагонали не считается).
Считай, что за пределами сетки везде вода.

## Примеры

grid = [
  "11110",
  "11010",
  "11000",
  "00000",
]
-> 1

grid = [
  "11000",
  "11000",
  "00100",
  "00011",
]
-> 3

## Ограничения

- 1 <= m, n <= 300
- grid[i][j] это '0' или '1'

## Подсказка

Можно мутировать grid, если надо. Рекурсия допустима, но подумай, что будет на 300x300.
