# Задача 45. Произведение цифр

Найти наименьшее натуральное Q, у которого произведение цифр равно N.
Если такого нет — вывести -1.

- Ввод: INPUT.TXT, одно целое N (0 ≤ N ≤ 10^9)
- Вывод: OUTPUT.TXT, число Q или -1
- Лимиты: 1 сек, 16 МБ

| INPUT | OUTPUT |
|-------|--------|
| 10    | 25     |
| 13    | -1     |
| 8     | 8      |
| 90    | 259    |

Крайние случаи (N = 0, N = 1, N < 10) продумай сам.
