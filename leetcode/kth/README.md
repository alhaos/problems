# 215. Kth Largest Element in an Array

Дан массив `nums` и число `k`. Верни k-й по величине элемент
(в отсортированном порядке по убыванию, а не k-й уникальный).

## Примеры
- `nums = [3,2,1,5,6,4], k = 2` -> `5`
- `nums = [3,2,3,1,2,4,5,5,6], k = 4` -> `4`

## Ограничения
- `1 <= k <= len(nums) <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## Челлендж
Без полной сортировки. Варианты:
- мин-куча размера k: O(n log k) по времени, O(k) по памяти;
- quickselect: O(n) в среднем.
