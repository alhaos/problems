# 15. 3Sum

Дан массив `nums`. Верни все **уникальные** тройки `[nums[i], nums[j], nums[k]]`,
где `i`, `j`, `k` попарно различны и `nums[i] + nums[j] + nums[k] == 0`.

Порядок троек и порядок чисел внутри тройки не важен.
Одна и та же тройка значений не должна встречаться дважды.

## Примеры

- `[-1,0,1,2,-1,-4]` -> `[[-1,-1,2],[-1,0,1]]`
- `[0,1,1]` -> `[]`
- `[0,0,0]` -> `[[0,0,0]]`

## Ограничения

- `3 <= len(nums) <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## Челлендж

O(n^2) по времени. Перебор трёх индексов (O(n^3)) на больших входах
не проходит.
