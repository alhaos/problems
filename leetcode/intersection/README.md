# 349. Intersection of Two Arrays

Даны два массива `nums1` и `nums2`. Верни массив их пересечения.
Каждый элемент в результате должен быть уникальным. Порядок любой.

## Примеры

nums1 = [1,2,2,1], nums2 = [2,2]  -> [2]
nums1 = [4,9,5],   nums2 = [9,4,9,8,4] -> [9,4] (или [4,9])

## Ограничения

- 1 <= len(nums1), len(nums2) <= 1000
- 0 <= nums[i] <= 1000

Реализуй `intersection` в intersection.go, чтобы проходили тесты.
