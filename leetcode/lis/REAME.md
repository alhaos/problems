# 300. Longest Increasing Subsequence

Дан массив целых `nums`. Верни длину самой длинной **строго возрастающей подпоследовательности**.

Подпоследовательность получается удалением нескольких элементов (возможно, нуля)
без изменения порядка остальных. Элементы не обязаны идти подряд.

## Примеры

Input: nums = [10,9,2,5,3,7,101,18]
Output: 4
(например, [2,3,7,101])

Input: nums = [0,1,0,3,2,3]
Output: 4

Input: nums = [7,7,7,7,7,7,7]
Output: 1

## Ограничения

- 1 <= len(nums) <= 2500
- -10^4 <= nums[i] <= 10^4

## Задача

Реализуй `lengthOfLIS` в `lis.go`, прогони `go test`.
Входной слайс менять нельзя.
