# 2248. Intersection of Multiple Arrays

Дан двумерный массив целых `nums`, где `nums[i]` — непустой массив
**различных** положительных чисел.

Верни список чисел, которые есть в **каждом** из массивов `nums[i]`,
отсортированный по возрастанию.

## Примеры

nums = [[3,1,2,4,5],[1,2,3,4],[3,4,5,6]] -> [3,4]
nums = [[1,2,3],[4,5,6]]                 -> []

## Ограничения

- 1 <= len(nums) <= 1000
- 1 <= sum(len(nums[i])) <= 1000
- 1 <= nums[i][j] <= 1000
- все значения внутри одного nums[i] различны
