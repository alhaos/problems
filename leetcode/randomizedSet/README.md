# Insert Delete GetRandom O(1)

## Задача

Реализовать структуру данных `RandomizedSet`, которая поддерживает следующие операции за **O(1)** в среднем:

- `Insert(val int) bool` — добавляет элемент в набор. Возвращает `true`, если элемент был добавлен, и `false`, если он уже присутствовал.
- `Remove(val int) bool` — удаляет элемент из набора. Возвращает `true`, если элемент был удален, и `false`, если его не было.
- `GetRandom() int` — возвращает случайный элемент из набора. Каждый элемент должен иметь одинаковую вероятность быть выбранным.

## Идея решения

### Проблема

Одна структура данных не может обеспечить O(1) для всех трех операций:

| Структура     | Insert | Remove | GetRandom |
|---------------|--------|--------|-----------|
| Map           | O(1)   | O(1)   | O(n)      |
| Slice (массив)| O(1)   | O(n)   | O(1)      |

### Решение: Гибридный подход

Используем **две структуры**:

1. **Map**: `value -> index` — для быстрого поиска и удаления за O(1)
2. **Slice**: хранит значения — для быстрого доступа к случайному элементу за O(1)

### Ключевая хитрость: Удаление за O(1)

При удалении элемента:

1. Находим его индекс в слайсе по мапе
2. Меняем местами с **последним** элементом в слайсе
3. Урезаем слайс (удаляем последний элемент)
4. Обновляем индекс перемещенного элемента в мапе
5. Удаляем ключ из мапы

Это позволяет избежать сдвига элементов в слайсе при удалении.

type RandomizedSet struct {
    data   map[int]int // значение -> индекс в слайсе
    values []int       // значения для рандомного доступа
}
