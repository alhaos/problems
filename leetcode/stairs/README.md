# 70. Climbing Stairs

Ты поднимаешься по лестнице из `n` ступенек. За один шаг можно
подняться на 1 или на 2 ступеньки. Сколькими различными способами
можно добраться до вершины?

## Примеры

- `n = 2` -> `2` (1+1, 2)
- `n = 3` -> `3` (1+1+1, 1+2, 2+1)

## Ограничения

- `1 <= n <= 45`

## Челлендж

O(n) по времени и O(1) по памяти.
