# 169. Majority Element

Дан массив `nums` длины `n`. Верни элемент, который встречается
строго больше `n/2` раз. Гарантируется, что такой элемент всегда есть.

## Примеры

- `[3,2,3]` -> `3`
- `[2,2,1,1,1,2,2]` -> `2`

## Ограничения

- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`

## Челлендж

O(n) по времени и O(1) по памяти.
