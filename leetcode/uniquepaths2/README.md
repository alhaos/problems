# Unique Paths II (LeetCode 63)

Робот стоит в левом верхнем углу сетки `m` на `n`. За один ход он может двигаться
только вправо или вниз. Он хочет попасть в правый нижний угол.

В сетке есть препятствия: `obstacleGrid[i][j] == 1` значит, что клетка занята,
`0` значит, что свободна. Через занятую клетку проходить нельзя.

Сколько существует различных путей?

Пример 1:
Input:  obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
Output: 2
Препятствие в центре. Пути: вправо-вправо-вниз-вниз и вниз-вниз-вправо-вправо.

Пример 2:
Input:  obstacleGrid = [[0,1],[0,0]]
Output: 1

Ограничения: 1 <= m, n <= 100, obstacleGrid[i][j] равно 0 или 1.
Ответ гарантированно не больше 2 * 10^9.
Цель: O(m * n) по времени. Бонус: O(n) по памяти.
