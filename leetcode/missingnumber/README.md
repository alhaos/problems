# 268. Missing Number

Дан массив `nums` из `n` различных чисел из диапазона `[0, n]`. Найди единственное число из этого диапазона, которого в массиве нет.

Follow up: время O(n), дополнительная память O(1).

Примеры:
- `[3,0,1]` -> `2`
- `[0,1]` -> `2`
- `[9,6,4,2,3,5,7,0,1]` -> `8`

Ограничения:
- n == len(nums)
- 1 <= n <= 10^4
- 0 <= nums[i] <= n
- все числа в nums уникальны
