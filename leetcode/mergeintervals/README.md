# 56. Merge Intervals

Дан массив интервалов `intervals`, где `intervals[i] = [start_i, end_i]`.
Объедини все пересекающиеся интервалы и верни массив непересекающихся
интервалов, которые покрывают все исходные.

Интервалы, которые касаются концами (`[1,4]` и `[4,5]`), считаются пересекающимися.

## Примеры

Input:  [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]

Input:  [[1,4],[4,5]]
Output: [[1,5]]

## Ограничения

- 1 <= len(intervals) <= 10^4
- len(intervals[i]) == 2
- 0 <= start_i <= end_i <= 10^4
- Входной массив НЕ гарантированно отсортирован

## Цель

O(n log n) по времени, без лишних структур.
