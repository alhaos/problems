# 120. Triangle

## Условие

Дан треугольник чисел, представленный как `[][]int`, где `triangle[i]` — 
i-я строка (индексация с 0), содержащая `i+1` элементов.

Начиная с вершины (индекс `[0][0]`), нужно найти путь до основания 
треугольника с минимальной суммой элементов.

На каждом шаге из позиции `triangle[row][col]` можно перейти только в:
- `triangle[row+1][col]`
- `triangle[row+1][col+1]`

## Пример

```
Input: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
Output: 11
```

Пояснение: минимальный путь — это `2 → 3 → 5 → 1` (сумма = 11).

Visual:
```
   2
  3 4
 6 5 7
4 1 8 3
```

## Ограничения

- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`
- `-10^4 <= triangle[i][j] <= 10^4`

## Follow-up

Могли бы вы решить задачу используя только O(n) дополнительной памяти, 
где n — количество строк в треугольнике?

## Сигнатура

```go
package triangle

func MinimumTotal(triangle [][]int) int
```

## Подход

**Bottom-up DP.**

Идём с последней строки треугольника вверх. Заводим `dp` — копию последней 
строки. Для каждой вышестоящей строки пересчитываем:

```
dp[i] = triangle[row][i] + min(dp[i], dp[i+1])
```

К моменту, когда доходим до строки 0, `dp[0]` содержит ответ — минимальную 
сумму пути.

Это естественно даёт O(n) память (без учёта самого треугольника), если не 
мутировать исходные данные, а завести отдельный слайс под dp.

**Сложность:**
- Time: O(n²), где n — количество строк
- Space: O(n) — для dp-слайса (или O(1) extra, если делать in-place прямо в triangle)
