# 347. Top K Frequent Elements

Дан массив целых `nums` и число `k`.
Верни `k` самых частых элементов. Порядок в ответе любой.

Гарантируется, что ответ однозначен (на границе top-k нет ничьей).

## Примеры

nums = [1,1,1,2,2,3], k = 2 -> [1,2]
nums = [1], k = 1           -> [1]

## Ограничения

- 1 <= len(nums) <= 10^5
- -10^4 <= nums[i] <= 10^4
- k в диапазоне [1, количество уникальных элементов]

## Follow-up

Сложность должна быть лучше, чем O(n log n).
Подумай про bucket sort (корзины по частоте) или min-heap размера k.
