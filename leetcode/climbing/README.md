# Climbing Stairs (LeetCode 70)

Вы поднимаетесь по лестнице из `n` ступенек. За один шаг можно подняться
на 1 или на 2 ступеньки. Сколькими различными способами можно добраться до вершины?

Пример 1:
Input:  n = 2
Output: 2
Способы: 1+1, 2

Пример 2:
Input:  n = 3
Output: 3
Способы: 1+1+1, 1+2, 2+1

Ограничения: 1 <= n <= 45

Подумай:
1. сколько способов добраться до ступеньки 1, до ступеньки 2
2. на ступеньку `i` можно прийти только с двух мест: откуда?
   как тогда число способов для `i` выражается через число способов для меньших ступенек
3. сколько данных реально нужно помнить, чтобы посчитать следующую ступеньку
   (полный массив на n элементов или меньше?)
