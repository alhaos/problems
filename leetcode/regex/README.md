# 10. Regular Expression Matching

Даны строка `s` и шаблон `p`. Верни `true`, если шаблон совпадает
с **всей** строкой `s` целиком (не с её частью).

Поддерживаются два спецсимвола:

- `.` совпадает с любым одним символом;
- `*` означает "ноль или больше копий предыдущего символа".

## Примеры

- `s = "aa", p = "a"` -> `false` (шаблон покрывает только один символ)
- `s = "aa", p = "a*"` -> `true`
- `s = "ab", p = ".*"` -> `true` (`.*` это "любые символы")

## Ограничения

- `1 <= len(s) <= 20`
- `1 <= len(p) <= 20`
- `s` состоит из строчных латинских букв
- `p` состоит из строчных букв, `.` и `*`
- перед каждым `*` всегда стоит буква или `.`

## Запрещено

Пакет `regexp` и подобное. Смысл задачи реализовать сопоставление самому.

## Челлендж
Динамическое программирование или рекурсия с мемоизацией:
O(len(s) * len(p)) по времени.
