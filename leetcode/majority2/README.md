# 229. Majority Element II

Дан массив `nums` длины `n`. Верни все элементы, которые встречаются
строго больше `n/3` раз (целочисленное деление). Порядок результата
не важен. Если таких нет, верни пустой слайс.

## Примеры
- `[3,2,3]` -> `[3]`
- `[1]` -> `[1]`
- `[1,2]` -> `[1,2]`

## Ограничения
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`

## Челлендж
O(n) по времени и O(1) по памяти.
