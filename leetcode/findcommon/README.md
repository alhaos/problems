# 1002. Find Common Characters

Дан массив строк `words`. Верни массив всех символов, которые встречаются
в каждой строке, с учётом повторов. Если символ встречается 3 раза во всех
строках, он должен быть в результате 3 раза (даже если в какой-то строке
он встречается больше). Порядок любой.

## Примеры

words = ["bella","label","roller"]  -> ["e","l","l"]
words = ["cool","lock","cook"]       -> ["c","o"]

## Ограничения

- 1 <= len(words) <= 100
- 1 <= len(words[i]) <= 100
- words[i] состоит из строчных английских букв

## Задание

Реализуй `commonChars` в common.go, чтобы проходили тесты.
