# 57. Insert Interval

Дан массив непересекающихся интервалов `intervals`, отсортированный по началу
(`intervals[i] = [start_i, end_i]`), и ещё один интервал `newInterval = [start, end]`.

Вставь `newInterval` в `intervals` так, чтобы результат остался отсортированным
и непересекающимся. При необходимости объедини пересекающиеся интервалы.
Касание концами считается пересечением.

## Примеры

Input:  intervals = [[1,3],[6,9]], newInterval = [2,5]
Output: [[1,5],[6,9]]

Input:  intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]

## Ограничения

- 0 <= len(intervals) <= 10^4
- intervals отсортирован по start и не содержит пересечений
- 0 <= start <= end <= 10^5

## Цель

O(n) по времени, без сортировки.
