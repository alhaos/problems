# Path Sum (LeetCode 112)

## Задача

Дано бинарное дерево `root` и целевая сумма `targetSum`.
Вернуть `true`, если существует путь от корня до **листа**, сумма значений
узлов на котором равна `targetSum`.

Путь обязательно должен заканчиваться в листе (узле без детей) — сумма,
совпавшая на промежуточном узле, не считается.

## Структура узла

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}
```

## Сигнатура

```go
func HasPathSum(root *TreeNode, targetSum int) bool
```

## Подход

DFS (обход в глубину) от корня, с накоплением суммы по текущему пути.

- Если узел `nil` — пути нет, `false`.
- Если узел — лист, путь до него валиден, если накопленная сумма равна `targetSum`.
- Иначе — рекурсивно проверяем `Left` и `Right`; достаточно, чтобы хотя бы
  одно поддерево дало `true`.

Ключевой нюанс: сумма проверяется **только** на листе, иначе можно поймать
ложное совпадение на промежуточном узле, у которого путь ещё не закончен.

Реализация использует замыкание с внешней переменной `sum` и backtracking
(`sum += node.Val` перед рекурсией, `sum -= node.Val` перед выходом) —
после того как обе ветки поддерева проверены и не дали результата, сумма
откатывается, чтобы не протечь в соседние ветки дерева.

## Сложность

- Время: `O(n)` — каждый узел посещается один раз.
- Память: `O(h)` — глубина стека рекурсии, где `h` — высота дерева
  (в худшем случае `O(n)` для вырожденного дерева-цепочки).
