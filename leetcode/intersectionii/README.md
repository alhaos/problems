# 350. Intersection of Two Arrays II

Даны два массива `nums1` и `nums2`. Верни массив их пересечения.
Каждый элемент встречается в результате столько раз, сколько он
встречается в обоих массивах (то есть минимум из двух счётчиков).
Порядок любой.

## Примеры

nums1 = [1,2,2,1], nums2 = [2,2]  -> [2,2]
nums1 = [4,9,5],   nums2 = [9,4,9,8,4] -> [4,9] (или [9,4])

## Ограничения

- 1 <= len(nums1), len(nums2) <= 1000
- 0 <= nums[i] <= 1000
