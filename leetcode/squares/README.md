# 977. Squares of a Sorted Array

Дан массив `nums`, отсортированный по неубыванию. Верни массив квадратов
каждого элемента, тоже отсортированный по неубыванию.

## Примеры

nums = [-4,-1,0,3,10]  -> [0,1,9,16,100]
nums = [-7,-3,2,3,11]  -> [4,9,9,49,121]

## Ограничения

- 1 <= len(nums) <= 10^4
- -10^4 <= nums[i] <= 10^4
- nums отсортирован по неубыванию

## Задание

Реализуй `sortedSquares` в squares.go, чтобы проходили тесты.

## Фолловап

Квадраты можно отсортировать за O(n log n), но попробуй решить за O(n).
