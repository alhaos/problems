# Maximum Subarray (LeetCode 53)

Дан массив целых чисел `nums`. Найдите непрерывный подмассив (минимум один элемент)
с наибольшей суммой и верните эту сумму.

Пример 1:
Input:  [-2,1,-3,4,-1,2,1,-5,4]
Output: 6   (подмассив [4,-1,2,1])

Пример 2:
Input:  [1]
Output: 1

Пример 3:
Input:  [5,4,-1,7,8]
Output: 23

Ограничения: 1 <= len(nums) <= 10^5, -10^4 <= nums[i] <= 10^4
Цель: O(n) по времени, O(1) по памяти.
