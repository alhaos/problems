# 93. Restore IP Addresses

Дана строка `s` из цифр. Верни все валидные IP-адреса, которые можно
получить, расставив в ней три точки (цифры переставлять и удалять нельзя).
Порядок результата не важен.

Валидный октет:
- число от 0 до 255
- без ведущих нулей ("0" можно, "00" и "01" нельзя)

## Примеры

| s             | результат                          |
|---------------|------------------------------------|
| "25525511135" | ["255.255.11.135","255.255.111.35"]|
| "0000"        | ["0.0.0.0"]                        |
| "101023"      | ["1.0.10.23","1.0.102.3","10.1.0.23","10.10.2.3","101.0.2.3"] |

## Ограничения

- 1 <= len(s) <= 20
- s состоит только из цифр
