# Kth Largest Element in a Stream (LeetCode 703)

Нужно спроектировать класс, который отслеживает k-й по величине элемент
в потоке чисел (k-й по величине в отсортированном порядке, не k-й различный).

- `NewKthLargest(k int, nums []int) *KthLargest` - инициализация k и начальным потоком nums
- `Add(val int) int` - добавляет val в поток и возвращает k-й по величине элемент

Пример: k = 3, nums = [4, 5, 8, 2]
Add(3)  -> 4    (поток: 2 3 4 5 8, третий с конца = 4)
Add(5)  -> 5
Add(10) -> 5
Add(9)  -> 8
Add(4)  -> 8

Замечания:
- в начальном nums может быть меньше k элементов
- `Add` гарантированно вызывается тогда, когда в потоке уже минимум k элементов
- память должна быть O(k), а не O(размер потока)

Подумай: какая куча нужна (min или max) и что лежит на её вершине, когда в ней ровно k элементов?
