# Top K Frequent Elements (LeetCode 347)

Дан массив целых чисел `nums` и число `k`. Верните `k` самых частых элементов.
Порядок в ответе любой.

Гарантируется, что ответ однозначен (нет "ничьей" на границе top-k).

Пример 1:
Input:  nums = [1,1,1,2,2,3], k = 2
Output: [1,2]

Пример 2:
Input:  nums = [1], k = 1
Output: [1]

Ограничения: 1 <= len(nums) <= 10^5, 1 <= k <= число уникальных элементов
Цель: лучше, чем O(n log n).
