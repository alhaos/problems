# Longest Substring Without Repeating Characters (LeetCode 3)

Дана строка `s`. Найдите длину самой длинной подстроки без повторяющихся символов.
Подстрока - непрерывная часть строки (не путать с подпоследовательностью).

Пример 1:
Input:  "abcabcbb"
Output: 3   (подстрока "abc")

Пример 2:
Input:  "bbbbb"
Output: 1   ("b")

Пример 3:
Input:  "pwwkew"
Output: 3   ("wke"; "pwke" - это подпоследовательность, не подстрока)

Ограничения: 0 <= len(s) <= 5 * 10^4
Строка состоит из букв, цифр, символов и пробелов (считай, что это ASCII).
Цель: O(n) по времени.
