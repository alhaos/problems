# 198. House Robber

Ты грабишь дома вдоль улицы. В каждом доме лежит `nums[i]` денег.
Нельзя грабить два соседних дома (сработает сигнализация).
Верни максимальную сумму, которую можно забрать.

## Примеры

- `[1,2,3,1]` -> `4` (дома 1 и 3: 1 + 3)
- `[2,7,9,3,1]` -> `12` (дома 1, 3 и 5: 2 + 9 + 1)

## Ограничения

- `1 <= len(nums) <= 100`
- `0 <= nums[i] <= 400`

## Челлендж

O(n) по времени и O(1) по памяти.
