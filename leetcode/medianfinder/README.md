# Find Median from Data Stream (LeetCode 295)

Медиана это средний элемент отсортированного списка. Если элементов чётное
количество, медиана это среднее арифметическое двух средних.

Спроектируйте структуру, которая поддерживает:
- `NewMedianFinder() *MedianFinder` - создание
- `AddNum(num int)` - добавить число из потока
- `FindMedian() float64` - вернуть медиану всех чисел на данный момент

Примеры:
[2]        -> медиана 2
[2,3]      -> медиана 2.5
[2,3,4]    -> медиана 3

Ограничения: -10^5 <= num <= 10^5. FindMedian вызывается, когда в потоке уже есть
хотя бы один элемент.
Цель: AddNum за O(log n), FindMedian за O(1).

Идея: поток делится на две половины.
- нижняя половина (меньшие числа): куча, на вершине которой НАИБОЛЬШЕЕ из них
- верхняя половина (большие числа): куча, на вершине которой НАИМЕНЬШЕЕ из них

Тогда середина лежит на вершинах этих двух куч.
Размеры куч должны отличаться не больше чем на 1.

Подумай:
1. какая из куч min, а какая max, и почему именно так
2. что делать с новым числом, чтобы не нарушить порядок (всё в нижней <= всё в верхней)
3. что делать, если размеры разошлись больше чем на 1
