# 5. Longest Palindromic Substring

Дана строка `s`. Верни самую длинную подстроку, которая читается
одинаково слева направо и справа налево (палиндром).

Если подходящих несколько, верни любую из них.

## Примеры

- `"babad"` -> `"bab"` (`"aba"` тоже подходит)
- `"cbbd"` -> `"bb"`
- `"a"` -> `"a"`

## Ограничения

- `1 <= len(s) <= 1000`
- `s` состоит из цифр и английских букв (ASCII)

## Челлендж

O(n^2) по времени и O(1) по памяти (без таблицы n*n).
Перебор всех подстрок с проверкой каждой это O(n^3), на больших входах медленно.

## Дополнительно

Алгоритм Манакера даёт O(n), но это отдельная история.
