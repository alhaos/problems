# Last Stone Weight (LeetCode 1046)

Дан массив `stones`, где `stones[i]` - вес i-го камня.

Каждый ход берём два самых тяжёлых камня с весами x <= y и разбиваем их:
- если x == y, оба камня уничтожаются
- если x != y, камень x уничтожается, а камень y получает вес y - x

Игра идёт, пока не останется не больше одного камня.
Верните вес оставшегося камня (или 0, если камней не осталось).

Пример 1:
Input:  [2,7,4,1,8,1]
Output: 1
Ходы: 8,7 -> 1; [2,4,1,1,1]; 4,2 -> 2; [2,1,1,1]; 2,1 -> 1; [1,1,1]; 1,1 -> 0; [1] -> 1

Пример 2:
Input:  [1]
Output: 1

Ограничения: 1 <= len(stones) <= 30, 1 <= stones[i] <= 1000
