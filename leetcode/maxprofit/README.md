# Best Time to Buy and Sell Stock (LeetCode 121)

Дан массив `prices`, где `prices[i]` - цена акции в день `i`.
Нужно выбрать один день для покупки и один более поздний день для продажи.

Верните максимальную прибыль. Если прибыли получить нельзя, верните 0.

Пример 1:
Input:  [7,1,5,3,6,4]
Output: 5   (купить за 1, продать за 6)

Пример 2:
Input:  [7,6,4,3,1]
Output: 0   (цена только падает)

Ограничения: 1 <= len(prices) <= 10^5, 0 <= prices[i] <= 10^4
Цель: O(n) по времени, O(1) по памяти.
