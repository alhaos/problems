# 78. Subsets

Дан массив `nums` из уникальных целых чисел. Верни все возможные подмножества (power set).
Результат не должен содержать одинаковых подмножеств. Порядок любой.

## Примеры

Input: nums = [1,2,3]
Output: [[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

Input: nums = [0]
Output: [[],[0]]

## Ограничения

- 1 <= len(nums) <= 10
- -10 <= nums[i] <= 10
- все числа в nums уникальны

## Задача

Реализуй `subsets` в `subsets.go`, прогони `go test`.
Решай через backtracking.
