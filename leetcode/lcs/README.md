# Longest Common Subsequence (LeetCode 1143)

Даны две строки `text1` и `text2`. Верните длину их самой длинной
общей подпоследовательности. Если общей подпоследовательности нет, верните 0.

Подпоследовательность получается удалением нуля или нескольких символов
без изменения порядка оставшихся. Символы не обязаны идти подряд.

Общая подпоследовательность двух строк - подпоследовательность, которая есть в обеих.

Пример 1:
Input:  text1 = "abcde", text2 = "ace"
Output: 3   ("ace")

Пример 2:
Input:  text1 = "abc", text2 = "abc"
Output: 3

Пример 3:
Input:  text1 = "abc", text2 = "def"
Output: 0

Ограничения: 1 <= len(text1), len(text2) <= 1000
Строки состоят из строчных английских букв.
Цель: O(m * n) по времени. Бонус: O(min(m, n)) по памяти.
