# House Robber (LeetCode 198)

Вы грабитель и идёте по улице с домами. В `nums[i]` лежит сумма денег в i-м доме.
Соседние дома связаны сигнализацией: если ограбить два соседних дома в одну ночь,
полиция приедёт. Нельзя грабить два соседних дома.

Верните максимальную сумму, которую можно украсть, не вызвав полицию.

Пример 1:
Input:  nums = [1,2,3,1]
Output: 4   (дом 1 и дом 3: 1 + 3)

Пример 2:
Input:  nums = [2,7,9,3,1]
Output: 12  (дома 1, 3, 5: 2 + 9 + 1)

Ограничения: 1 <= len(nums) <= 100, 0 <= nums[i] <= 400
Цель: O(n) по времени, O(1) по памяти.

Подумай:
1. у тебя есть лучший ответ для первых `i` домов. Подходишь к дому `i`:
   какие у тебя два варианта (брать его или нет)?
2. чему равна сумма в каждом из вариантов, и откуда берутся нужные для этого числа
3. сколько прошлых значений нужно помнить (сравни с Climbing Stairs)
