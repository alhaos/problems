# 253. Meeting Rooms II

Дан массив интервалов встреч `intervals`, где `intervals[i] = [start_i, end_i]`.
Верни минимальное количество переговорок, которое нужно, чтобы провести все встречи.

Если одна встреча заканчивается в момент `t`, а другая начинается в момент `t`,
они могут идти в одной комнате (касание не считается конфликтом).

## Примеры

Input:  [[0,30],[5,10],[15,20]]
Output: 2

Input:  [[7,10],[2,4]]
Output: 1

Input:  [[1,5],[5,10]]
Output: 1

## Ограничения

- 1 <= len(intervals) <= 10^4
- 0 <= start_i < end_i <= 10^6
- Входной массив НЕ гарантированно отсортирован

## Цель

O(n log n) по времени.
