# 101. Symmetric Tree

Дан корень бинарного дерева. Проверь, является ли оно зеркально симметричным
относительно своего центра.

## Примеры

[1,2,2,3,4,4,3]       -> true
[1,2,2,null,3,null,3] -> false

## Ограничения

- узлов: от 1 до 1000
- значения: от -100 до 100

## Задача

Реализуй `isSymmetric(root *TreeNode) bool`.
Сначала рекурсивно. Если захочется, потом итеративная версия (очередь).
