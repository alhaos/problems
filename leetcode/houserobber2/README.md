# House Robber II (LeetCode 213)

Те же правила, что в House Robber (198): нельзя грабить два соседних дома.
Но теперь дома стоят по кругу, то есть первый и последний дом тоже соседи.

Верните максимальную сумму, которую можно украсть.

Пример 1:
Input:  nums = [2,3,2]
Output: 3
Дома 1 и 3 соседи (по кругу), так что 2 + 2 брать нельзя. Лучше взять средний.

Пример 2:
Input:  nums = [1,2,3,1]
Output: 4   (дом 1 и дом 3: 1 + 3)

Пример 3:
Input:  nums = [1,2,3]
Output: 3

Ограничения: 1 <= len(nums) <= 100, 0 <= nums[i] <= 1000
Цель: O(n) по времени, O(1) по памяти.

Подумай (рецепт из четырёх вопросов):
1. что значит ответ для линейной улицы (ты это уже решил в 198)
2. в круге первый и последний дома нельзя брать оба одновременно.
   Какие два случая из этого получаются? Что можно сказать про каждый из них?
3. как каждый из двух случаев сводится к линейной задаче на более коротком массиве
4. чему равен итоговый ответ и какой угловой случай есть при len = 1
