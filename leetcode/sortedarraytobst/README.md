# 108. Convert Sorted Array to Binary Search Tree

Дан массив целых чисел, отсортированный по возрастанию. Преобразуй его
в **height-balanced** бинарное дерево поиска.

Height-balanced: для каждого узла высоты левого и правого поддеревьев
отличаются не больше чем на 1.

## Примеры

[-10,-3,0,5,9] -> [0,-3,9,-10,null,5]  (или [0,-10,5,null,-3,null,9])
[1,3]          -> [3,1]                (или [1,null,3])

Верных ответов может быть несколько, годится любой.

## Ограничения

- длина массива: от 1 до 10^4
- значения: от -10^4 до 10^4
- массив строго возрастает

## Задача

Реализуй `sortedArrayToBST(nums []int) *TreeNode`.
