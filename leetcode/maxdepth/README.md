# Maximum Depth of Binary Tree (LeetCode 104)

Дано бинарное дерево. Верните его максимальную глубину:
количество узлов на самом длинном пути от корня до листа.

Пример 1:
Input:  root = [3,9,20,null,null,15,7]
Output: 3

      3
     / \
    9   20
       /  \
      15   7

Пример 2:
Input:  root = [1,null,2]
Output: 2

Пустое дерево: глубина 0.

Ограничения: число узлов от 0 до 10^4, -100 <= Val <= 100

Подумай:
1. чему равна глубина пустого дерева (nil)
2. как глубина дерева выражается через глубину его левого и правого поддеревьев
