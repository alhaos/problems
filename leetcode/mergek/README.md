# Merge k Sorted Lists (LeetCode 23)

Дан массив из `k` связных списков `lists`, каждый отсортирован по возрастанию.
Слейте их в один отсортированный список и верните его голову.

Пример 1:
Input:  lists = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]

Пример 2:
Input:  lists = []
Output: []

Пример 3:
Input:  lists = [[]]
Output: []

Ограничения: 0 <= k <= 10^4, суммарно узлов до 10^4.
Цель: O(N log k), где N - общее число узлов.

Идея: в куче лежит по одному текущему (самому левому) узлу каждого списка.
Достаёшь минимум, добавляешь в результат и кладёшь в кучу следующий узел
из того же списка.

Подумай: сколько элементов в куче в любой момент времени?
