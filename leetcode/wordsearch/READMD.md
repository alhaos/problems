# 79. Word Search

Дана сетка символов `board` размером m x n и строка `word`.
Верни `true`, если `word` есть в сетке.

Слово собирается из последовательно соседних клеток (по горизонтали или вертикали,
по диагонали нельзя). Одну и ту же клетку нельзя использовать в слове дважды.

## Примеры

board = [["A","B","C","E"],
         ["S","F","C","S"],
         ["A","D","E","E"]]

word = "ABCCED" -> true
word = "SEE"    -> true
word = "ABCB"   -> false

## Ограничения

- 1 <= m, n <= 6
- 1 <= len(word) <= 15
- board и word состоят из английских букв

## Задача

Реализуй `exist` в `word_search.go`, прогони `go test`.
Решай через backtracking (DFS). Входную сетку после вызова менять нельзя.
