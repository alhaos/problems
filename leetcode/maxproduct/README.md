# Maximum Product Subarray (LeetCode 152)

Дан массив целых чисел `nums`. Найдите непрерывный подмассив (минимум один элемент)
с наибольшим произведением и верните это произведение.

Пример 1:
Input:  [2,3,-2,4]
Output: 6   (подмассив [2,3])

Пример 2:
Input:  [-2,0,-1]
Output: 0   (ответ не может быть 2, потому что [-2,-1] не подмассив)

Ограничения: 1 <= len(nums) <= 2 * 10^4, -10 <= nums[i] <= 10
Произведение любого подмассива помещается в 32-битный int.
Цель: O(n) по времени, O(1) по памяти.
