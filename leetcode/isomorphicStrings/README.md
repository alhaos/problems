# 205. Isomorphic Strings

## Условие

Даны две строки `s` и `t`. Нужно проверить, изоморфны ли они: можно ли
построить биекцию (взаимно однозначное соответствие) между символами `s`
и символами `t`, такую что если заменить в `s` каждый символ на
соответствующий из `t`, получится ровно `t`.

Примеры:

- `"egg"`, `"add"` → true (e→a, g→d)
- `"foo"`, `"bar"` → false (o должно мапиться и в a, и в r)
- `"paper"`, `"title"` → true

## Подход

Два `map[byte]byte` — один для `s→t`, другой для
`t→s`. Идём по обеим строкам одновременно, на каждом шаге проверяем
согласованность в обе стороны.

- Время: O(n)
- Память: O(1) (алфавит ограничен)
