# 1207. Unique Number of Occurrences

Дан массив целых `arr`.

Верни `true`, если количество вхождений каждого значения в массиве
уникально, иначе `false`.

## Примеры

arr = [1,2,2,1,1,3] -> true   (1 встречается 3 раза, 2 — 2 раза, 3 — 1 раз)
arr = [1,2]         -> false  (1 и 2 встречаются по одному разу)
arr = [-3,0,1,-3,1,1,1,-3,10,0] -> true

## Ограничения

- 1 <= len(arr) <= 1000
- -1000 <= arr[i] <= 1000
