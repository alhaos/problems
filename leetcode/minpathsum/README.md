# Minimum Path Sum (LeetCode 64)

Дана сетка `grid` размером `m` на `n`, заполненная неотрицательными числами.
Найдите путь из левого верхнего угла в правый нижний, который минимизирует
сумму всех чисел на пути (включая начальную и конечную клетки).
За один ход можно двигаться только вправо или вниз.

Пример 1:
Input:  grid = [[1,3,1],[1,5,1],[4,2,1]]
Output: 7
Путь 1 -> 3 -> 1 -> 1 -> 1 (вправо, вправо, вниз, вниз).

Пример 2:
Input:  grid = [[1,2,3],[4,5,6]]
Output: 12

Ограничения: 1 <= m, n <= 200, 0 <= `grid[i][j]` <= 200
Цель: O(m * n) по времени. Бонус: O(n) по памяти.
