# 136. Single Number

Дан непустой массив целых `nums`. Каждый элемент встречается дважды, кроме одного. Найди этот один.

Требования: время O(n), дополнительная память O(1).

Примеры:
- `[2,2,1]` -> `1`
- `[4,1,2,1,2]` -> `4`
- `[1]` -> `1`

Ограничения:
- 1 <= len(nums) <= 3 * 10^4
- -3 * 10^4 <= nums[i] <= 3 * 10^4
