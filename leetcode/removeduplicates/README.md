# Remove Duplicates from Sorted Array (LeetCode 26)

Дан массив `nums`, отсортированный по неубыванию. Уберите дубликаты in-place так,
чтобы каждый уникальный элемент встречался один раз, порядок сохраняется.

Верните `k` - количество уникальных элементов. Первые `k` элементов `nums`
должны содержать уникальные значения по порядку. Что лежит после `k`, не важно.

Пример:
Input:  [0,0,1,1,1,2,2,3,3,4]
Output: k = 5, nums[:k] = [0,1,2,3,4]

Ограничения: 1 <= len(nums) <= 3 * 10^4, массив отсортирован
Без доп. памяти (O(1)).
