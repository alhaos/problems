# Unique Paths (LeetCode 62)

Робот стоит в левом верхнем углу сетки размером `m` строк на `n` столбцов.
За один ход он может двигаться только вправо или вниз.
Робот хочет попасть в правый нижний угол.

Сколько существует различных путей?

Пример 1:
Input:  m = 3, n = 7
Output: 28

Пример 2:
Input:  m = 3, n = 2
Output: 3
Пути: вправо-вниз-вниз, вниз-вправо-вниз, вниз-вниз-вправо

Ограничения: 1 <= m, n <= 100
Ответ гарантированно не больше 2 * 10^9.
Цель: O(m * n) по времени. Бонус: O(n) по памяти.
